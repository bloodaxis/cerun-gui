# Cerun GUI

A Qt frontend for launching executables inside a running Steam compatibility
prefix.

## Install

Download `cerun-gui-local-v1.0.0.tar.gz` from the latest release and extract it
into `~/.local`:

```bash
tar -xzf cerun-gui-local-v1.0.0.tar.gz -C ~/.local
```

Requires `/usr/bin/python3` with PySide6 installed. The launcher, desktop entry,
and user-theme icon are installed under the standard `~/.local` directories.
